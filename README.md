# POPGRID

Renkli, mobil öncelikli 8×8 blok bulmaca oyunu. React + TypeScript + Vite ile sıfırdan geliştiriliyor.

**Yayın:** https://ncg0659.github.io/popgrid/

## Durum
- [x] Aşama 1 — Proje kurulumu ve saf oyun motoru
- [ ] Aşama 2 — Görsel arayüz
- [ ] Aşama 3 — Mobil sürükleme
- [ ] Aşama 4 — Animasyon ve ses
- [ ] Aşama 5 — Cila ve yayın hazırlığı

## Komutlar
```bash
npm install      # bağımlılıkları kur
npm run dev      # geliştirme sunucusu
npm test         # Vitest testleri
npm run lint     # ESLint
npm run build    # yayın paketi (dist/)
npm run sim      # kurtarma şansı simülasyonu → docs/sim-results.md
```
